初學者指南：全面認識 Ubuntu 作業系統
最後更新：2025年3月4日

Linux 並不像 Windows 或 macOS 那樣由單一公司（如微軟或蘋果）完全掌控，而是 一個開源專案，任何人都可以下載原始碼並自行修改。

因此，不同的團隊或組織 會根據自己的需求，從 Linux 核心（Kernel） 開始，加上不同的軟體、工具、桌面環境，並打包成不同的發行版，來適應不同的使用情境。

這就像是「積木遊戲」—— 每個團隊都可以使用相同的「Linux 核心」，但組裝出來的系統可能會大不相同。
Linux 發行版的主要差異

不同的 Linux 發行版主要在以下幾個方面有所不同：
差異點	說明
目標使用者	有些發行版適合新手（如 Ubuntu），有些適合資深用戶（如 Arch Linux）。
軟體管理機制	不同發行版使用不同的 套件管理系統（如 Ubuntu 用 apt，Fedora 用 dnf，Arch 用 pacman）。
桌面環境（GUI）	有些發行版預設提供 GNOME、KDE、Xfce 等不同風格的桌面環境。
穩定性 vs. 新技術	有些發行版（如 Debian、Ubuntu LTS）專注於穩定性，而有些（如 Arch Linux、Fedora）會提供最新技術。
專門用途	一些發行版是為特定用途而設計的，例如 Kali Linux（駭客與安全測試）、Ubuntu Server（伺服器）、Raspberry Pi OS（單板電腦）。
為什麼 Windows 沒有發行版？

Windows 是 微軟專屬的閉源系統，由微軟統一管理、開發與發行，因此不會有第三方團隊自行修改 Windows 核心或發布不同的變種。

微軟唯一提供的不同版本只是針對不同需求（如 Windows Home、Windows Pro、Windows Server），但它們本質上仍是同一個 Windows 系統。

相比之下，Linux 是開放原始碼的，因此任何人或公司都可以自由修改並發佈自己的版本，這就是為什麼 Linux 有這麼多不同的發行版。
常見的 Linux 發行版分類

Linux 發行版可以大致分成幾個主要類別：
（1）適合新手

這些發行版強調 易用性，適合從 Windows 轉換過來的使用者：

    Ubuntu（最受歡迎，適合大部分人）
    Linux Mint（類似 Windows，介面友善）
    Zorin OS（專為 Windows 用戶設計的 Linux）

（2）適合進階用戶

這些發行版提供更大的 自訂空間，適合對 Linux 有一定了解的用戶：

    Debian（Ubuntu 的母版，穩定但軟體較舊）
    Fedora（Red Hat 的社群版，使用較新技術）
    openSUSE（適合開發者與 IT 人員）

（3）適合專家

這些發行版提供更高的靈活性，但需要使用者 手動配置：

    Arch Linux（極致客製化，需要自己從零安裝）
    Gentoo（程式碼編譯導向，適合進階玩家）

（4）特殊用途

這些發行版針對特定領域設計：

    Kali Linux（資訊安全與滲透測試）
    Ubuntu Server（伺服器管理）
    Raspberry Pi OS（適用於樹莓派硬體）

什麼是 Ubuntu？

在眾多 Linux 發行版（Linux Distributions）中，Ubuntu 是最受歡迎的一款。

它不僅適合個人使用者，也廣泛應用於伺服器、雲端運算、人工智慧（AI）和開發環境。

對於剛接觸 Linux 的初學者來說，Ubuntu 提供了一個 直覺、易於學習且強大的作業系統，同時還擁有龐大的社群支援與定期更新的版本。

本篇文章將詳細介紹 Ubuntu 的歷史、版本、特點、安裝步驟、基本指令 以及如何在日常使用中充分發揮其強大功能，讓你能夠輕鬆上手 Ubuntu 並探索其無限可能性！
Ubuntu 的起源與歷史

Ubuntu 是由 Canonical Ltd. 所開發並維護的 Linux 發行版，最早於 2004 年 由 南非企業家 Mark Shuttleworth 推出，目標是讓 Linux 更適合一般使用者，並提供一個免費、開源且易於使用的作業系統。

Ubuntu 這個名字源自 南非祖魯語「Ubuntu」，意思是「人性化精神」（”I am because we are”）。這與 Ubuntu 作業系統的理念一致，即讓所有人都能輕鬆獲得高品質的軟體。
Ubuntu 的特色

Ubuntu 以其 穩定性、易用性和社群支持 而聞名，以下是它的幾個主要特點：

    免費與開源：Ubuntu 完全免費，並基於開放原始碼，任何人都可以下載、修改或分享它。
    使用者友善：提供直覺式的 GNOME 桌面環境，適合新手與 Windows 使用者。
    軟體相容性高：擁有 Ubuntu 軟體中心，並支援 APT（Advanced Package Tool） 來安裝各種應用程式。
    高安全性：內建 防火牆與自動安全更新，比起 Windows 更不容易受到病毒與惡意軟體攻擊。
    適用於伺服器與雲端運算：Ubuntu 伺服器版（Ubuntu Server）被廣泛應用於 AWS、Azure、Google Cloud 等雲端平台。
    活躍的社群支援：擁有龐大的 官方論壇 和 Stack Overflow，遇到問題時可以輕易找到解決方案。

Ubuntu 的版本與選擇
LTS（長期支援版） vs. 非 LTS 版本

Ubuntu 每 兩年 會推出一個 LTS（Long-Term Support） 長期支援版，並提供 5 年的安全與系統更新，適合企業或個人穩定使用。

相對地，每 6 個月發布的非 LTS 版本 只提供 9 個月支援，適合想體驗最新功能的用戶。
版本	發布週期	支援年限	適合對象
LTS 版本（如 20.04、22.04）	每 2 年發布	5 年（企業可延長至 10 年）	企業用戶、伺服器、長期穩定使用者
非 LTS 版本（如 21.10、23.04）	每 6 個月發布	9 個月	開發者、想嘗試最新技術的用戶
Ubuntu 的不同變體

除了標準的 Ubuntu Desktop 和 Ubuntu Server 之外，Ubuntu 還有許多變體，適合不同需求的使用者：

    Kubuntu：使用 KDE Plasma 桌面環境，適合喜歡自訂界面的用戶。
    Xubuntu：使用 Xfce 桌面環境，適合 舊電腦，佔用資源較少。
    Lubuntu：超輕量版本，適合 低規格電腦 或極簡環境。
    Ubuntu MATE：使用 MATE 桌面環境，類似傳統 GNOME 2 界面。
    Ubuntu Studio：專為 音樂、影片、圖像創作 而設計，內建多種多媒體工具。

如何安裝 Ubuntu？

Ubuntu 可以安裝在 實體電腦 上，也可以透過 WSL 2（Windows Subsystem for Linux 2） 在 Windows 內部執行，適合不想改變現有 Windows 系統的使用者。
在電腦上安裝 Ubuntu（傳統方式）
下載與準備
下載 Ubuntu ISO

    前往官方網站：https://ubuntu.com/download
    選擇 Ubuntu Desktop 或 Ubuntu Server（建議新手選擇 LTS 版本）。

建立 USB 啟動碟

    Windows 用戶 可使用 Rufus 來製作 USB 開機碟。
    macOS 用戶 可使用 balenaEtcher。

設定 BIOS/UEFI

    重新啟動電腦，進入 BIOS / UEFI（通常按 F2、F12 或 Del）。
    設定 USB 為第一開機選項，然後重新啟動。

Ubuntu 安裝步驟

    選擇語言 ➝ 選擇「繁體中文」或其他語言。
    選擇安裝類型：
        標準安裝（包含瀏覽器、辦公軟體等）。
        最小安裝（僅安裝基本系統）。
    磁碟分割：
        自動安裝（建議新手使用）。
        手動分割（適合雙系統用戶）。
    建立使用者帳號 ➝ 設定使用者名稱與密碼。
    等待安裝完成 ➝ 重新啟動系統並移除 USB。

在 WSL 2（Windows Subsystem for Linux 2） 上安裝 Ubuntu

如果不想安裝雙系統，可以使用 WSL 2，在 Windows 上直接執行 Ubuntu，適合開發者或初學者輕鬆體驗 Linux。
在 WSL 2 上安裝 Ubuntu
安裝 Ubuntu（如果 wsl --install 未自動安裝）

wsl --install -d Ubuntu

或手動從 Microsoft Store 安裝：

打開 Microsoft Store ➝ 搜尋 Ubuntu ➝ 安裝。
啟動 Ubuntu

安裝完成後，在 Windows 搜尋 Ubuntu 並打開。

Ubuntu 會要求 設定使用者名稱與密碼（這與 Windows 帳戶無關）。
更新系統套件

執行以下命令，確保 Ubuntu 內的軟體是最新的：

sudo apt update && sudo apt upgrade -y

開始使用 Ubuntu！

現在你可以直接在 Windows 內執行 Linux 指令，如：

ls
pwd
cd /mnt/c

Ubuntu 基本操作與指令
桌面環境

Ubuntu 預設使用 GNOME 桌面環境，提供類似 macOS 風格的操作介面：

    應用程式選單：按 Super（Windows 鍵） 開啟應用程式啟動器。
    工作區（Workspace）：可使用 Ctrl + Alt + ↑/↓ 切換不同桌面。

基本指令

以下是 Ubuntu 常見的 Linux 指令：
指令	功能
ls	列出目前資料夾的檔案
cd	切換資料夾，例如 cd /home
pwd	顯示當前目錄
mkdir myfolder	建立資料夾
rm -r myfolder	刪除資料夾
sudo apt update	更新套件列表
sudo apt upgrade	安裝更新
sudo apt install firefox	安裝應用程式
ps aux	顯示執行中的程序
kill <PID>	強制終止某個程序
Ubuntu 的日常應用

    瀏覽網頁：內建 Firefox 瀏覽器，也可安裝 Chrome。
    辦公應用：LibreOffice 替代 Microsoft Office。
    程式開發：支援 Python、Java、C++，可安裝 VS Code。
    遊戲：透過 Steam 或 Lutris 來玩遊戲。
    伺服器管理：Ubuntu Server 廣泛用於網站託管、資料庫管理等。

結語

Ubuntu 是一款 免費、強大、穩定 的 Linux 發行版，不論是日常使用、開發、伺服器管理，甚至是機器學習，它都能滿足需求。

如果你是新手，Ubuntu 是進入 Linux 世界的最佳選擇！ 🚀
